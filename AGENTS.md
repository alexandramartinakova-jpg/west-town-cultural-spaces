# House Rules for This Project

- **Single File Architecture**: Build one HTML file with all the CSS and JavaScript inside it. No build tools.
- **Mobile-First**: It must work on a phone screen first.
- **Factual Grounding**: Never invent facts, numbers, names or quotes. Use only what I give you, and put `[NEED SOURCE]` where something's missing.
- **Attribution**: Put a source link next to every fact.
- **Testing Disclosure**: Before you say "done," list what you tested and what you couldn't test.
- **Strict Scope**: Change only what I ask you to change.
